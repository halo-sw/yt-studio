# channels/ — 채널 중심 관리 구조

파이프라인(공장)은 `data/`에 그대로 있고, 여기는 **사람이 보는 채널 서랍**이다.

```
channels/
├─ 소재함/          # 중앙 소재 메모리 — 어느 채널이든 여기서 소재를 꺼내 간다
└─ <채널이름>/
   ├─ 말투.md       # 이 채널의 목소리·어미·구조 (대본 쓸 때 반드시 참조)
   ├─ 롱폼/         # 발행용 완성본 (영상+썸네일+업로드 텍스트, 슬러그별 폴더)
   ├─ 숏폼/         # 숏츠 완성본
   └─ 브랜딩/        # 채널 아이콘·배너·범퍼·썸네일 템플릿 등 채널 자산
```

## 규칙

- **완성본의 집은 여기다.** `python cli.py release --slug <슬러그>`가 트랙→채널 매핑
  (`data/channels.yaml`)을 보고 자동으로 `channels/<채널>/롱폼/<슬러그>/`에 수집한다.
  채널이 아직 없는 트랙(부동산 등)은 예전처럼 `data/releases/`에 대기한다.
- **소재는 소재함에서 시작한다.** 소재 카드는 사람 말로 쓴다 — 표·코드·전문용어 말고,
  "누가 왜 끝까지 보는가"가 한 줄로 읽히게. 채널 배정이 확정되면 카드에 채널 이름을 적는다.
- **말투.md가 채널의 헌법이다.** 대본·업로드 텍스트·고정댓글 전부 이 문서의 톤을 따른다.
  트랙 공용 규칙(CLAUDE.md)과 충돌하면 말투.md(채널 커스텀)가 이긴다.
- 중간 산출물(작업 폴더·오디오 캐시·비주얼 원본)은 여기 두지 않는다 — 그건 공장(`data/assets/produce`) 소관.
