# 소재함 — 중앙 소재 메모리

모든 채널의 소재가 여기서 시작한다. 채널별 백로그 파일(`<채널이름>.md`)에 카드를 쌓고,
아직 채널이 정해지지 않은 아이디어는 `미배정.md`에 둔다.

## 카드 양식 (사람 말로 — 기획서 아니고 메모)

```markdown
## <소재 한 줄 — 시청자가 클릭할 문장으로>
- 왜 지금: (시의성·트렌드·경쟁 채널 반응 등 한 줄)
- 누가 끝까지 보나: (타깃과 그 사람이 얻는 것)
- 참고: (링크·레퍼런스 영상, 있으면)
- 상태: 아이디어 → 소재 확정 → 대본 완료 → 제작 중 → 발행됨
```

카드를 쓸 때 지킬 것:

- **제목 줄이 곧 훅이다.** "회피형 애착 편" ✕ → "읽씹하는 사람이 답장을 못 하는 진짜 이유" ✓
- 숫자·이론명·출처는 카드 단계에선 대충이어도 된다. 대본 단계에서 사실 시트로 검증한다.
- 다른 100개 채널에 있어도 되는 소재면 버린다 (YPP 제네릭 판정 기준이기도 하다).
- 고통 전시형(동물·아동 학대 중심), 의료 조언형(진단·치료)은 카드 단계에서 걸러낸다.
