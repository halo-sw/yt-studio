# 기획서 01 — 에이전트 레일 + 에이전트 워크스페이스

## 1. 개요

모든 화면 좌측에 상주하는 내비게이션 레일. 에이전트 5개(일본 머니 / 부동산 /
드라마썰 / 사연 / 플레이리스트)의 실시간 상태를 한눈에 보여주고, 클릭하면 해당
에이전트의 워크스페이스(그 채널의 카드·에피소드만 모아 보는 뷰)로 진입한다.
주 사용자: 3인 전원, 접속 직후 항상.

## 2. 목표·성공 기준

- 접속 3초 안에 "지금 어느 채널이 돌아가고 있고, 어디가 멈춰 있는지"가 보인다.
- 데모 합격 기준: 레일에서 상태 뱃지가 서로 다른 에이전트 2개 이상이 보이고,
  클릭 시 워크스페이스가 해당 채널 데이터로 전환된다.

## 3. 사용자 시나리오

- A가 아침에 접속 → 레일에서 "드라마썰: 검토 대기" 뱃지 확인 → 클릭 →
  워크스페이스에서 대기 중인 에피소드로 이동.
- B가 렌더 걸어두고 퇴근 전 확인 → 레일 "일본 머니: 렌더 중 72%" → 그대로 로그아웃.

## 4. 화면 구성 (뎁스 표기는 00_ia-depth-map 규약, 멀티에이전트 문법은 07 참조)

- **D0 레일 (좌측 고정, 폭 260px 내외)**: 상단 스튜디오 로고 → 에이전트 5개
  카드(채널명, 상태 뱃지, 진행 중 작업 1줄, **미니 진행률 바**, 사람 대기 시
  `사람 대기` 점멸 배지) → 하단 전역 메뉴(홈, 만들기, 편집, 함께 결정, 기록).
- **D1 워크스페이스 (본문)** — 에이전트 1명의 관제 화면. 3단 구성:
  1. **지금 하는 일**: 현재 실행 중 에피소드의 파이프라인 스테퍼(대본→목소리→
     그림→조립→검토→예약) + 실시간 활동 로그 스트림("TTS: 씬 14/28 녹음 ·
     실측 41.2초" 화법 — Devin식 실행 투명성).
  2. **소재 카드 보드**: 상태 컬럼 칸반(새 소재 / 확정됨 / 제작 중 / 검토 대기 /
     예약됨). 카드 클릭 → D2 카드 상세.
  3. **바이블 요약 드로어(D3)**: voice·금지어 개수·BGM 세트 — 읽기 전용, 잠금 표시.
- **D2 소재 카드 상세**: 아웃라이어 근거(점수·경쟁 채널 배수)·출처·요약,
  owner/확정자 박스와 액션(내가 맡기 / 소재 확정 / 만들기 시작), 이 카드의
  이력 타임라인. 우리 파이프라인의 '계획 체크포인트'(07 §C) — 확정 전에
  사람이 근거를 확인하는 지점.
- **D2 에피소드 실행 상세**: 스테퍼 + 로그 전체 + 산출물(대본 씬 목록) —
  조립 완료 시 "편집 화면으로" 핸드오프.

## 5. 핵심 인터랙션

- 에이전트 카드 클릭 → 워크스페이스 전환. 브레드크럼 `홈 › {에이전트}`.
- 상태 뱃지: `대기` `대본 쓰는 중` `녹음 중` `렌더 중(%)` `검토 대기` `예약됨`
  `실패` + **`사람 대기`**(HITL 인터럽트 — 어떤 게이트에서 몇 시간째인지 툴팁).
  statemachine 상태의 일상어 표기. 개발 용어(scripted, voiced)는 노출 금지.
- 보드 카드 클릭 → D2 상세, 상세의 **내가 맡기** / **소재 확정** /
  **만들기 시작**(→ 03 생성 플로우, 카드 프리필).
- 상태 문구 화법 통일: "에이전트가 ~하는 중" / "에이전트가 ~를 기다려요".

## 6. 데이터·API 매핑

- 레일 뱃지: `EpisodeModel.state`를 채널별 집계 (`GET /agents` — M2 라우터).
- 워크스페이스 카드: `CardModel` (track 필터), 에피소드: `EpisodeModel`.
- 바이블 요약: `core.schemas.load_bible(track)` — 읽기 전용, 수정 UI 없음.

## 7. 절대 규칙 반영 (§5)

- **5-4 클레임 잠금**: owner 있는 카드는 다른 사람에겐 잠금 아이콘 + 버튼 비활성.
- 바이블은 잠금 자산 — 워크스페이스에서 절대 편집 불가(요약 표시만). 변경은
  3인 합의 후 yaml 직접 수정.

## 8. 엣지케이스

- 에피소드가 하나도 없는 채널: 뱃지 `대기` + 워크스페이스에 "소재 카드를
  확정하면 시작됩니다" 빈 상태 안내.
- 렌더 잡 실패(재시도 2회 소진): 뱃지가 `실패` (적색)로 바뀌고 클릭 시 로그로 연결 (§5-8).

## 9. 데모 체크리스트

- [ ] 레일에 에이전트 5개와 상태 뱃지·미니 진행률이 모두 렌더된다
- [ ] 사람 대기 중인 에이전트에 `사람 대기` 배지가 보인다
- [ ] 에이전트 클릭 시 워크스페이스 데이터가 채널별로 바뀌고 브레드크럼이 갱신된다
- [ ] 워크스페이스에 스테퍼 + 활동 로그 + 칸반 보드가 보인다
- [ ] 보드 카드 클릭 → D2 카드 상세 → 브레드크럼으로 복귀 가능
- [ ] owner 있는 카드가 타인 시점에서 잠금 표시된다
- [ ] 바이블 영역에 편집 컨트롤이 없다 (읽기 전용 드로어)
