# 자체 채널 90일 운영 플랜 (엔진 A 주력 확정)

> ⚠ **대체됨**: 검토 이력 원본. 통합본은 `docs/plans/00_master-plan.md`, 실행 기준은 `docs/PLAYBOOK.md`.

> plans/13에서 자체 채널 중심으로 재편. 대행(B)·대본 판매(C)는 보류하되
> 언제든 재가동 가능한 상태 유지 (파이프라인은 동일).

## 0. 목표 재정의 — 정직하게

자체 채널 단독으로 90일 내 현금 1,000만원은 확률이 낮다 (YPP 정산 시차 포함).
따라서 90일의 실질 목표는 **수익 파이프의 완성**으로 둔다:

1. **쇼츠 수익화 요건 달성**: 90일 쇼츠 조회 1,000만 뷰 (또는 롱폼 시청 4,000시간)
2. 첫 정산 발생 + 상위 소재 축 식별 (무엇이 터지는 채널인지 데이터 확보)
3. 이 시점부터 월 수익이 복리로 붙는 구조 — 1,000만원은 90일 '내'가 아니라
   90일 '시스템'이 만든다. (조기 현금이 필요해지면 plans/13 B안 즉시 재가동)

## 1. 성장 모델 — 쇼츠 깔때기

```
데일리 쇼츠(발견·유입) → 롱폼(시청시간·RPM) → 시리즈 일관성(구독 전환)
```

- 쇼츠는 유입 장치, 돈은 롱폼 시청시간에서 나온다. 쇼츠에서 검증된 소재만 롱폼화.
- 구독 전환의 핵심은 **시그니처 일관성**: 같은 문체(냐옹체), 같은 마무리 패턴
  ("여러분이라면 ~했을까요?"), 같은 비주얼 톤 — 바이블(recap.yaml)이 잠금.

## 2. 콘텐츠 슬레이트 (주간)

| 요일 | 콘텐츠 | 파이프라인 |
|---|---|---|
| 매일 | 창작 스토리 쇼츠 1편 (60~90초) | prompts/01·02 → `produce --shorts` |
| 화·금 | 사연 롱폼 10분 (natepan 재창작) | prompts/03 → `produce --track natepan` |
| 일 | 쇼츠 중 최고 성과작 → 롱폼 확장판 | 02 롱폼 스펙으로 재생성 |

## 3. 소재 5축 로테이션 + 지표 피드백

쇼츠 소재를 5축으로 돌리고, harvest 지표(24h/7d)로 배분을 재조정한다:

| 축 | 감정 | 첫 배치 대본 (data/scripts/) |
|---|---|---|
| 미스터리→감동 | 궁금증이 뭉클함으로 | gyeongbiwon(경비원), bakery(빵집) |
| 직장 반전 | 통쾌 | drawer(서랍) |
| 일상 속 비밀 | 따뜻한 반전 | delivery(택배) |
| 관계 회복 | 감동 | milk(우유) |
| 생존/긴장 | 몰입 | (2주차 추가 — 데이터 보고 결정) |

규칙: **7일 조회수 상위 2축에 주간 물량의 60% 배분, 최하위 축은 교체.**
같은 스토리의 훅만 바꾼 재업로드는 금지 (중복 콘텐츠 판정 리스크).

## 4. 90일 마일스톤

- **D+7**: 쇼츠 7편 발행 + 보이스 확정 + 채널 아트/소개 피봇 정리
- **D+30**: 쇼츠 30편 · 구독 +1,000 · 상위 축 식별 완료 · 첫 롱폼 8편
- **D+60**: 쇼츠 60편 · 롱폼 16편 · 시청시간 2,000시간 페이스 확인
  - 미달 시: 상위 축 집중 + plans/13 B안(대행) 병행 재개 판단
- **D+90**: 쇼츠 1,000만 뷰 또는 4,000시간 → YPP 완전 요건 → 정산 개시

## 5. 발행 체크리스트 (편당, 사람 ~15분)

1. 소재 확정 (prompts/01 카드, 게이트 1)
2. 대본 생성 → `produce` (린트 위반 행만 재생성)
3. 제목·썸네일 (prompts/04 — 낚시 금지선 준수)
4. 예약 업로드 (피크 1시간 전: 쇼츠 18시, 롱폼 19시 시작점 — 지표로 보정)
5. 발행 후 첫 댓글 고정 (다음 화 예고 or 질문) — 초기 댓글 밀도가 노출에 기여
