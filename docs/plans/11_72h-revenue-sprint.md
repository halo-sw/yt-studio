# 72시간 수익 스프린트 — "100만원 벌어와" 실행 계획

> ⚠ **대체됨**: 이 문서는 검토 이력이다. 운영 기준은 `docs/PLAYBOOK.md` 하나만 따른다.

> 참고 요청: [윤자동 | AI 자동화 크리에이터 (@yun_ja_dong)](https://www.threads.com/@yun_ja_dong)
> — 전 토스 PO, 자동화 회사 운영(직원 5명), 유튜브 구독자 5만+, 자동화 강의·에이전시.
> 핵심 방법론: **반복 작업을 시스템에 위임하고, 그 자동화 역량 자체를 상품화한다.**

## 0. 정직한 전제 (먼저 읽을 것)

- **신규 채널 광고수익으로 72시간 내 100만원은 불가능하다.** YPP(수익창출)
  가입 조건이 구독자 1,000명 + 시청 4,000시간이고 심사만 수 주가 걸린다.
  "AI 자동화로 즉시 월 천만원" 류는 과대광고다 — 윤자동 본인 포지션도
  '즉시 수익'이 아니라 **자동화 시스템 구축 → 반복 산출 → 복리**다.
- 따라서 72시간의 목표를 둘로 나눈다:
  1. **자산 완성**: 돈이 되는 마지막 구간(영상 실제 산출)을 완성한다 ✅ ← 이번 스프린트에서 완료
  2. **단기 현금화**: 완성된 파이프라인 산출력을 외부에 파는 경로를 연다 (아래 3장)

## 1. 이번 스프린트에서 완성된 것 (M1 달성)

| 구간 | 상태 | 증빙 |
|---|---|---|
| 대본 생성 (script.py) | ✅ 기존 | 씬 26개·3,406자·콘테 4요소 |

| **조립 playlist_1h** | ✅ 신규 | loudnorm→크로스페이드→루프 비주얼→타임스탬프. 3곡 176.3초 미니 렌더 검증 |
| **조립 longform_16x9** | ✅ 신규 | Ken Burns+자막 번인+2트랙 믹스(-14/-26 LUFS)+챕터 마커. 10분 목표 e2e로 7.3분 영상 실렌더 |

ElevenLabs 보이스 확정(바이블 voice_id가 TODO)과 비주얼 수동 대기열뿐이다.

## 2. 72시간 타임라인 (3인 공동 운영 기준)

### Day 1 (0~24h) — 발행 가능 영상 2편 산출
- [ ] ElevenLabs 보이스 5개 확정 → `data/bibles/*.yaml` voice_id 기입 (30분)
- [ ] `python cli.py e2e --track japan --minutes 12` → 일본 머니 12분 1편
- [ ] 플레이리스트 60분 1편 (`preset_playlist_1h`, 라이선스 확인 곡만 — 규칙 5-5)
- [ ] 비주얼: MJ 수동 대기열로 씬 이미지 교체 (플레이스홀더 → 실이미지)
- 사람 게이트: 소재 확정 1회 + 최종 검토 1회 (설계대로 2곳만)

### Day 2 (24~48h) — 발행 + 재고 쌓기
- [ ] 예약 초안 업로드 → 사람이 공개 전환 (규칙 5-6 하이브리드)
- [ ] 파이프라인 반복: 트랙당 1편씩 추가 (일 3편 목표 — 병목은 비주얼 대기열)
- [ ] 채널 개설 직후 SEO: 제목 3안 A/B, 타임스탬프·챕터는 자동 산출물 사용

### Day 3 (48~72h) — 단기 현금화 경로
- [ ] **제작 대행 영업** (아래 3장 A안): 산출 샘플 2편을 포트폴리오로
- [ ] 커뮤니티(스레드/블로그)에 "자동화 파이프라인으로 만든 영상" 빌드 공개
  — 윤자동식 빌드-인-퍼블릭. 채널 성장과 대행 문의를 동시에 노린다

## 3. 100만원까지의 현실적인 경로 (우선순위순)

**A. 롱폼 제작 대행 (72h 내 유일하게 현실적)**
- 시세: 10분+ 롱폼 편집·제작 대행 편당 15~40만원.
- 우리 원가: API 비용 편당 ~1만원 이하(대본+TTS) + 사람 검토 30분.
- **편당 20만원 × 5편 = 100만원.** 파이프라인이 하루 3편을 뽑으므로
  물리적으로 가능 — 병목은 수주(영업)이지 생산이 아니다.

**B. 자체 채널 (복리 자산 — 72h 밖, 그러나 본편)**
- 수익화 도달 후 기대치: 재테크·사연 트랙 RPM $2~5 기준
  조회 10만/월 ≈ 30~70만원/월. 5트랙 병렬이 설계 근거.

**C. 파이프라인 자체의 상품화 (윤자동 모델)**
- 자동화 시스템 구축 대행·강의는 단가가 크지만(건당 수백만원)
  실적·신뢰 자산이 먼저 필요하다. A·B의 증빙이 쌓인 뒤의 경로.

## 4. 이번 스프린트가 지킨 절대 규칙

- 5-1 오디오 2트랙: 씬 세그먼트에 BGM을 굽지 않음 — 최종 믹스에서만 -26 LUFS 언더베드
- 5-2 부분 재생성: replace_scene은 세그먼트 1개만 재렌더, 경계 80ms 크로스페이드
- 5-3 사실 시트: {{fact:key}}는 합성/번인 직전 치환, 없는 키는 즉시 실패
- 5-5 라이선스: library.ingest가 license_meta 없는 곡을 거부 (조립 직전 재검증 포함)
- 5-7 길이 제어: TTS 실측 duration 기입, 챕터 마커 자동 산출
- 5-8 사용량: 문자수 로그 + 재생성 별도 집계(is_regen)
