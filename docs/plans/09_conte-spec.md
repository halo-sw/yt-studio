# 기획서 09 — 콘테 사양: 전문 유튜버 대본의 씬 단위 연출 정보

> 이 서비스의 핵심은 "전문 유튜버 스크립트를 잘 생성하는 것"이다 (v5 최종
> 실행 보고서). 내레이션 텍스트만으로는 영상이 되지 않으므로, 씬 JSON을
> **콘테**로 승격한다 — 씬마다 정보전달·감정전달·구도·시각을 함께 생성한다.

## 콘테 스키마 (core/schemas.py `Conte`)

| 요소 | 필드 | 내용 | 소비처 |
|---|---|---|---|
| 정보전달 | `info_point` | 이 씬이 전달하는 **단 하나의 정보** (1씬 1포인트, 직전 씬과 중복 금지) | 검토 화면, qc |
| 감정전달 | `emotion.tone` | 감정 톤 — 트랙별 감정 아크를 따름 | 검토 화면 |
| | `emotion.delivery` | 낭독 지시: 속도·쉼 위치·강조 단어 | tts.py (보이스 파라미터·포즈) |
| 구도 | `composition` | 샷 사이즈(와이드/미디엄/클로즈업) + 피사체·시선 + 자막 여백 | assemble.py (Ken Burns 방향, 자막 위치) |
| 시각 | `visual_direction` | 만들 사람이 그대로 만들 수 있는 연출 설명 (소재·톤·효과) | 수동 대기열 (MJ 프롬프트), visuals/ |

## 생성 규칙 (core/script.py가 프롬프트로 강제)

1. **트랙별 구성 블루프린트** (`TRACK_STRUCTURES`, v5 보고서 §3 원문):
   - 일본: 훅(손익 질문 40초) → 페르소나 인사 → 제도 기본 → 케이스 계산 A/B → 함정·반전 → 체크리스트 → 아웃트로
   - 부동산: 9챕터 (훅 → 온이 인사 → 개요 → 자격 6항목×4비트 → 일정 → 비용 계산 → 함정 → 신청 방법 → 아웃트로)
   - 드라마썰: 콜드오픈 → 맥락·스포일러 고지 → 핵심 장면 해석 3~4 (요약 짧게·분석 길게) → 반전 분석 → 결말 해석+대안 → 공개 비하인드 → CTA
   - 네이트판: 사연 도입 → 갈등 전개 → 절정 → 정리·질문 (모티프 결합 재창작)
   - 플레이리스트: 인트로 카드 → 큐레이션 노트 → 아웃트로
   각 챕터에 **목적과 감정 톤**이 붙어 있고, 씬의 `emotion.tone`은 이 아크를 따른다.
2. **감정 아크 연속성**: 직전 씬에서 자연스럽게 이어질 것. 급락·급등 금지,
   미드롤 직전은 반드시 긴장 피크 (공통 길이 공학과 결합).
3. **컷 리듬**: 같은 샷 사이즈 3연속 금지, `visual.type` 3연속 동일 금지,
   글자 많은 화면(차트·자료) 다음은 여백 있는 화면.
4. **마지막 챕터는 댓글 유도**로 끝난다 (보고서 공통 길이 공학).
5. 부분 재생성(규칙 5-2) 시에도 콘테 4요소를 다시 채우고 앞뒤 감정 톤에 잇는다.

## 검증 (core/script.py `lint_conte`)

- 4요소 누락, 샷 3연속, visual.type 3연속, 연속 씬 info_point 중복을 감지.
- 위반 씬은 qc 실패가 아니라 **부분 재생성 대상 지정**에 사용한다.

## UI 반영 (demo, 편집 화면)

장면 카드 = 좌측 시각(종류/사람·자동/연출 설명) + 우측 시나리오(내레이션,
**정보/감정(톤 칩+낭독 지시)/구도** 3행, 자막, 클리프행어 표시). 만들기
화면의 프롬프트 확인 패널에 구성·감정 아크와 콘테 규칙이 노출된다.
