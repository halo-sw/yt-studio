# 90일 1,000만원 수익 시스템 — 운영 프레임워크

> ⚠ **대체됨**: 이 문서는 검토 이력이다. 운영 기준은 `docs/PLAYBOOK.md` 하나만 따른다.

> 목표: 3개월 내 누적 수익 1,000만원.
> 전제: M1 파이프라인 완성(완료), 리캡 트랙 완성(완료), YPP 조건 일부 확보 채널 보유.

## 0. 정직한 수익 수학 — 어디서 1,000만원이 나오는가

| 엔진 | 3개월 기대치 | 근거 | 역할 |
|---|---|---|---|
| **B. 제작 대행 (주력)** | **600~900만원** | 편당 15~30만원 × 월 10~20편. 파이프라인 원가 편당 ~1만원 + 사람 30분 → 생산이 아니라 **수주가 병목** | 현금 엔진 |
| A. 자체 채널 (피봇 채널 + 신규) | 50~250만원 | 쇼츠 RPM은 낮음(회당 ~0.1원대). 롱폼 진입 후 RPM 2~5$. 3개월 내 광고수익은 보조 | 성장 자산 + B의 포트폴리오 |
| C. 대본 패키지 판매 | 50~150만원 | 냐옹체·사연 대본 건당 3~8만원, 재능마켓. 등록 후 유입 시차 있음 | 회전 보조 |
| **합계** | **700~1,300만원** | 중앙값이 목표선. **B 수주 실패 시 목표 미달** — 아래 KPI 게이트로 조기 감지 | |

광고수익만으로 3개월 1,000만원은 불가능하다. **이 시스템의 본체는 "파이프라인 산출력을 파는 것"이고,
자체 채널은 그 증빙이다.** (윤자동 모델: 자동화 역량 자체의 상품화)

## 1. 주간 운영 케이던스 (3인 기준, 사람 시간 주 10~15h)

| 요일 | 자동 (파이프라인) | 사람 (게이트 2곳 + 영업) |
|---|---|---|
| 매일 | 쇼츠 1~2편 생산 (`cli.py produce`) | 최종 검토·발행 전환 15분 |
| 월 | 소재 큐 갱신 (scout 아웃라이어) | 소재 확정 30분 |
| 화·목 | 롱폼 1편 렌더 | 검토 30분 |
| 수·금 | — | **대행 영업: 아웃리치 10건 + 견적 응답** (docs/prompts/05) |
| 토 | 주간 지표 리포트 (harvest) | KPI 게이트 점검 15분 |

## 2. KPI 게이트 — 미달 시 즉시 방향 수정

- **2주차**: 포트폴리오 3편 완성 + 크몽/숨고 등록 완료. 미달 → 다른 것 전부 중단하고 이것만
- **4주차**: 첫 유료 수주 1건 + 쇼츠 누적 20편. 수주 0건 → 단가 인하(10만원)로 레퍼런스 우선 확보
- **8주차**: 월 300만원 페이스(수주 누적 10편+) + 채널 구독 전환율 확인. 미달 → C(대본 판매)로 축 이동
- **12주차**: 누적 1,000만원. A채널이 YPP 수익 발생 시작이면 성공 조건 초과

## 3. 자동화 프레임워크 — 명령 한 줄 매핑

| 단계 | 명령 | 사람 개입 |
|---|---|---|
| 소재 발굴 | `scout` 폴링 + `docs/prompts/01` | 소재 확정 클릭 |
| 대본 생성 | `docs/prompts/02·03` → Claude → 대본 파일 | 프롬프트 실행 (키 연동 시 자동) |
| 검수 | style_lint 자동 (produce에 내장) | 위반 씬만 확인 |
| **제작·편집** | **`python cli.py produce --script 대본.txt --title "..." [--shorts]`** | 없음 |
| 패키징 | produce가 meta.txt(제목·설명·챕터) 자동 생성 | 썸네일 문구 선택 (`docs/prompts/04`) |
| 업로드 | M3 publish (그전까지 Studio 수동 10분) | 예약 확인·공개 전환 |
| 대행 납품 | 동일 파이프라인 + `docs/prompts/05` 견적 템플릿 | 브리프 협의 |

## 4. 트랙 포트폴리오 (90일 범위)

1. **창작 스토리 리캡 (recap 트랙, 저작권 리스크 0)** — 쇼츠 주력. 냐옹체 + AI 비주얼
2. **사연 (natepan)** — 롱폼 주력. 모티프 결합 재창작
3. **플레이리스트** — 주 1편, 저노동 재고 축적
4. 일본 머니/부동산은 90일 범위에서 보류 (감수·파서 비용 대비 단기 수익 기여 낮음)

## 5. 리스크와 방어선 (기존 절대 규칙이 이미 방어 중)

- 양산형 판정(YPP): 큐레이션 노트·비평/재창작 의무·사람 게이트 = 비진정성 방어
- 저작권: 라이선스 게이트(permission_ref 필수)·원본 오디오 미사용·민감 표현 자동 치환
- 채널 급피봇 리스크: 쇼츠로 신포맷 테스트 → 반응 확인 후 본편 확장
- 번아웃: 사람 시간 주 15h 상한 — 초과하면 자동화 안 된 구간을 찾아 코드로 옮긴다
