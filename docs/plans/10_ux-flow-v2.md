> 전면 재정렬한 기준 문서. demo_mock.html이 이 사양의 구현체다.

## 1. 큐(cue) 승인 구조 — 권한 게이트 제거

- **원칙**: 접속한 사람 누구나 큐를 승인·처리한다. "내가 맡기(클레임 잠금)"와
  "제작자 셀프 검수 차단"의 UI 게이트를 모두 제거.
- 아바타(A/B/C)는 권한이 아니라 **기록용 신원** — 누가 승인했는지 감사
  로그에 남는 것으로 책임을 진다 (모든 승인 토스트·이력에 처리자 표기).
- **CLAUDE.md §5-4와 상충**: 클레임 잠금·셀프 검수 금지는 브리프의 절대
  규칙이었다. 이 완화는 사용자 결정이므로 §5-4 개정을 함께 결정(2/3)으로
  확정할 것. (서버 레이어 statemachine.py의 강제 로직 제거 여부 포함)

## 2. 단일 파이프라인 (이전 비일관 수정)

발견된 비일관: ① 만들기의 ④조립과 편집의 합치기가 중복 ② 검토 큐가
드라마인데 편집은 일본 에피소드 ③ 발행·완성 결과물을 보는 곳이 없음.

수정된 흐름 (모든 화면·큐·상태가 이 순서 하나를 따른다):

```
경쟁 채널 감지 → [소재 승인 큐] → 만들기: 대본→목소리→그림(사람 대기 포함)
  → [콘테 확인 큐] → 편집(스토리보드): 장면 다듬기 → 하나의 영상으로 합치기
  → 완성본 재생·확인 → [확인 끝] → 발행 예약(확인 다이얼로그)
  → 홈 '완성된 영상'으로 이동 → verify → 조회수·수익 집계
```

- 만들기는 **재료 준비까지**(3단계). 합치기는 콘테 확인 후 편집에서만.
- 예약 완료 시 "만들어지는 중" 타일이 "완성된 영상"으로 자동 이동.

## 3. 완성된 영상 영역 (신규)

- 홈 하단 "완성된 영상" 갤러리: 발행·예약본 타일(길이·발행일·조회수).
- 클릭 → **플레이어 오버레이**: 재생/일시정지, 시킹 바, 타임코드.
  편집의 완성본 재생 버튼도 같은 플레이어를 쓴다. (실서비스에선 최종
  렌더 mp4; 데모는 목 재생)

## 4. 경쟁 채널 분석 · 예상 수익 (기록 3번째 탭)

- **경쟁 채널**: 채널별 주 업로드 수·중앙값 조회수·최근 아웃라이어(배수)
  + "우리 버전 소재로" → 소재 승인 큐 생성. (core/scout.py 리포트 매핑)
- **예상 수익**: v5 보고서 §7 역산 — 트랙별 조회수 × RPM(일본 5,000 /
  부동산 3,500 / 드라마·사연 2,000 / 플레이리스트 1,000원), 합계를
  고정비 60만 기준 1×/3×(180만) 마커 게이지로. 성수기(11~12월 단가
  1.5~2×) 힌트 포함. M4 harvest.py의 실측 지표가 이 표를 채운다.

## 5. 소재 허브 · 분석 · 프롬프트 편집 (v2.1 추가)

- **소재 (신규 D1)**: 소재는 계속 생성된다 — ① 직접 추가(주제 입력+채널
  선택, Enter 지원) ② 자동 발굴 상태 바("지금 확인" 즉시 실행) ③ 백로그
  (대기/승인됨/보류 필터). 대기 소재가 곧 홈 승인 큐다(단일 저장소 동기화).
  승인됨 → "만들기" 버튼으로 생성 진입, 보류 → "다시 올리기".
- **분석 (신규 D1)**: 기록 탭에 있던 경쟁 채널·예상 수익을 독립 화면으로
  승격. "우리 버전 소재로"는 소재 저장소에 대기 항목을 만든다.
- **프롬프트 편집 (D3 시트)**: 만들기 프롬프트 패널의 "수정하기" → 트랙별
  페르소나·구성(챕터|감정 줄 단위)·금지어를 자유 수정. 저장 즉시 다음
  생성부터 적용 + 수정자·내용이 감사 로그에 기록. 길이 제어·사실 시트·
  콘테 4요소는 잠금(변경은 함께 결정). 기본값 복원 제공.
- 내비게이션: 홈/소재/만들기/편집/분석/함께 결정/기록 7개 — §10 화면 수
  제한(5+워크스페이스)을 초과하므로 브리프 개정을 함께 결정에 포함할 것.

## 6. 소재 다중 소스 체계 (v2.2 — FeiGe 워크플로 이식)

소재 큐는 세 가지 소스를 포괄한다 (목록에 출처 배지로 구분):

| 소스 | 배지 | 경로 | 백엔드 |
|---|---|---|---|
| 자동 발굴 | 자동 | 경쟁 채널 아웃라이어 → 큐 | core/scout.py |
| 직접 추가 | 직접 | 소재 탭 컴포저 (주제+채널) | — |
| 영상 역해부 | 역해부 | 레퍼런스 URL → 4단계 분석 → 큐 | **core/breakdown.py (신규)** |

**영상 역해부** — FeiGe(로컬 AI 영상 拆片 도구, 바이너리 배포라 공개 문서
기준으로 이식)의 4단계: ① 준비(ffmpeg 씬 경계 감지) ② 분해(샷·컷 리듬
— 평균 컷·훅 밀도) ③ 콜라주(균등 버킷×최장 샷으로 대표 12샷 자동 선정)
④ 종합(비전 모델 → 팔레트·무드·훅 문법·구도 문법·응용법 = StyleStudy).

- StyleStudy는 소재 큐 항목과 **콘테 힌트**(script.py visual_direction/
  composition 참조 블록) 양쪽으로 흘러간다.
- 규칙 5-5 가드: to_material()이 "원본 모방 아닌 구조 응용" 문구를 강제하고,
  종합 프롬프트에도 저작권 주의가 명시된다. UI에도 "원본 재현 금지 —
  문법만 응용" 고지.
- UI: 소재 탭 역해부 컴포저(URL→4단계 진행) + 스타일 연구 시트(12샷
  콜라주·팔레트 스와치·문법 표·"콘테 생성에 참조").

## 7. 함께 결정(투표)의 위치

권한 게이트는 없어졌지만 **내용 결정**(제목·썸네일·바이블 변경·규칙 개정)은
여전히 2/3 투표를 거친다 — 큐 승인(운영)과 방향 결정(거버넌스)의 분리.
