# 기획서 08 — 디자인 디렉션 B: 크리에이션 툴형 (Midjourney/Runway 문법)

> 07(관제 대시보드형)에 이은 두 번째 디자인 방향. 목표는 **극단적 사용성** —
> 화면당 결정 1개, 클릭 1~2번으로 모든 일이 끝나는 구조.
> demo_mock.html이 현재 이 방향으로 구현돼 있다 (Direction A는 git 이력
> `1ab4b1f`에 보존).

## 참조 문법 → 반영

| 레퍼런스 | 문법 | 반영 |
|---|---|---|
| Runway | 슬림 아이콘 레일 + 콘텐츠 풀블리드 | 좌측 64px 아이콘 레일 5개(홈/만들기/편집/함께 결정/기록), 텍스트 레이블은 툴팁으로 |
| Midjourney | 생성이 곧 첫 화면, 결과는 큰 타일 갤러리 | 홈 = "지금 할 일" 큰 카드 한 줄 + "만들어지는 중" 16:9 썸네일 갤러리 |
| Runway 생성 플로우 | 소재 선택 → 옵션 칩 → 큰 버튼 하나 | 만들기 화면: 소재 3택 → 칩 → "만들기 시작" 단일 CTA, 진행은 대형 시네마 카드(% + 4단계) |
| Higgsfield/공통 | 상세는 페이지 이동 없이 오버레이 | 카드 상세 = 우측 슬라이드 오버 (열기 1클릭, 닫기 1클릭/ESC) |

## 사용성 원칙 (이 방향의 계약)

1. **화면당 결정 1개**: 홈=처리, 만들기=시작, 편집=승인/재생성, 투표=선택.
2. **버튼 수 상한**: 할 일 카드 = 주 버튼 1 + 보조 1. 그 이상은 슬라이드 오버로.
3. **글보다 그림**: 상태는 썸네일 위 칩과 진행 바로. 문장은 카드당 1줄.
4. **개발 용어 0**: "목소리 만들기가 멈췄어요", "다 만들어졌어요" 화법.
5. **뎁스 축소**: 00의 D2(카드 상세 페이지)를 슬라이드 오버(D3 승격)로 대체.
   브레드크럼 없음 — 뎁스가 2단(화면→오버레이)뿐이라 필요가 없다.
6. 절대 규칙은 그대로: 셀프 검수 차단 안내, 클레임 잠금("○ 카드 · 잠김"),
   BGM 글로벌 트랙, 장면 단위 재생성, 2/3 투표 즉시 결정.
