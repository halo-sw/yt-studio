# 기획서 04 — 편집 화면 (CapCut식 타임라인)

## 1. 개요

조립 완료된 에피소드를 검토·수정하는 화면. 프리뷰 캔버스 + 멀티트랙 타임라인 +
선택 장면 패널. 부분 재생성("이 장면만 다시 만들기")의 홈이자 최종 검토(게이트 2)가
일어나는 곳. 주 사용자: owner(수정), 리뷰어(검토·승인).

## 2. 목표·성공 기준

- 씬 하나 고치는 데 전체 재렌더 없이 "장면 클릭 → 다시 만들기 → 이음새 확인"
  3단계로 끝난다.
- 데모 합격 기준: 타임라인에서 장면 선택 → 패널의 두 버튼("이 장면만 다시
  만들기", "이음새 듣기")이 동작하는 흐름이 보이고, 리뷰어 시점에서 승인 버튼이,
  owner 시점에서는 승인 불가 안내가 보인다.

## 3. 사용자 시나리오

- B(owner): 렌더 완료 알림 → 7번 씬 발음 이상 → 타임라인에서 7번 클릭 →
  **이 장면만 다시 만들기** → 완료 후 **이음새 듣기**로 6→7→8 경계 확인 →
  검토 요청.
- C(리뷰어): 홈 피드에서 진입 → 전체 훑기 → **검토 완료** → 발행 예약으로.

## 4. 화면 구성

- 상단: 프리뷰 캔버스(16:9) + 재생 컨트롤 + 챕터 점프.
- 중단: 멀티트랙 타임라인 4트랙 — `장면`(씬 블록, scene_id·챕터 색), `자막`,
  `목소리`(씬별 파형), `BGM`(**에피소드 전체를 가로지르는 글로벌 트랙 1줄** —
  씬 경계와 무관함이 시각적으로 보여야 함).
- 우측: 선택 장면 패널 — 내레이션 텍스트(수정 가능), 비주얼 썸네일, 실측 길이,
  버튼: **이 장면만 다시 만들기** / **이음새 듣기**.
- 하단 바: 총 길이(씬 duration 합) / 목표 길이, 미드롤 마커(4/7/10분), **검토 요청**·**검토 완료**·**발행 예약**.

## 5. 핵심 인터랙션

- 장면 블록 클릭 → 패널 로드. 내레이션 수정 후 **이 장면만 다시 만들기** →
  해당 씬만 재생성 잡(대본 수정분→음성→렌더), 타임라인에 재생성 중 표시.
- **이음새 듣기**: 선택 씬 경계 앞뒤 3초 재생(크로스페이드 확인용).
- BGM 트랙은 선택·편집 불가(교체는 바이블 bgm_set 내에서만, 전역 적용).
- 리뷰어의 **검토 완료** → reviewed 전환 → **발행 예약** 활성화.

## 6. 데이터·API 매핑

- 타임라인: `SceneModel` (scene_id 순, duration, audio_path, visual).
- 다시 만들기: `POST /scenes/{id}/regen` → RQ `regen_scene` 잡 —
  바이블 잠금 자산 + `prev_tail/next_head` 자동 주입 (§5-2).
- 검토 완료: `POST /review/{episode_id}/approve` → `statemachine.approve_review`.
- 발행 예약: `POST /episodes/{id}/schedule` → publish.py (예약 초안 업로드).

## 7. 절대 규칙 반영 (§5)

- **5-1 오디오 2트랙**: BGM은 글로벌 트랙 1줄로만 표시·씬과 함께 편집 불가.
  씬 재생성이 BGM을 건드리지 않음을 UI 구조가 그대로 반영.
- **5-2 부분 재생성**: 수정 진입점이 씬 단위뿐 — "전체 다시 만들기" 버튼은 없다.
  경계 크로스페이드는 "이음새 듣기"로 사람이 확인.
- **5-4 셀프 검수 금지**: owner 시점에는 검토 완료 버튼 대신 "내 영상은 내가
  승인할 수 없어요 — 검토 요청을 보내세요" 안내. 서버도 403으로 이중 방어.
- **5-3 사실 시트**: 내레이션의 `{{fact:key}}`는 값으로 치환 표시하되 밑줄 강조,
  클릭 시 fact_sheet 출처 팝오버. 직접 수치 타이핑 시 경고.
- **5-7**: 하단 바에 총 길이/목표, 미드롤 마커 상시 표시.

## 8. 엣지케이스

- 재생성 중 같은 씬 재클릭: 진행 중 잡 상태 표시, 중복 잡 금지.
- 재생성 후 길이 변동으로 미드롤 지점 이동: 마커 재계산 + 배지 알림.
- fact_sheet 갱신됨: 해시 불일치 차트 씬에 "다시 그려야 함" 플래그 (§5-3, qc).

## 9. 데모 체크리스트

- [ ] 4트랙 타임라인에서 BGM이 전체 폭 글로벌 트랙으로 보인다
- [ ] 장면 선택 → 패널에 두 버튼이 보인다
- [ ] "이 장면만 다시 만들기" 후 해당 씬만 갱신된 것이 표시된다
- [ ] owner 시점에서 검토 완료가 차단된다 (안내 문구)
- [ ] 미드롤 마커(4/7/10분)가 타임라인에 보인다
