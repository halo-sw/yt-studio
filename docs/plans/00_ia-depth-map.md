# 기획서 00 — 정보 구조(IA)와 세부 뎁스 정의

> 모든 화면 기획서(01~06)가 공유하는 내비게이션 뎁스 규약.
> "새 화면"과 "기존 화면의 하위 뎁스"를 구분하는 기준이기도 하다 —
> §10 스코프 규칙은 **D1(최상위 화면)** 추가에만 적용되고,
> D2/D3은 해당 화면 기획서 개정으로 추가할 수 있다.

## 뎁스 4단계

| 뎁스 | 정의 | 예 | 이동 방식 |
|---|---|---|---|
| **D0** | 전역 프레임 — 항상 떠 있음 | 에이전트 레일, 상단 바(브레드크럼 + 보는 사람 전환) | 없음(상주) |
| **D1** | 최상위 화면 (§10 스코프 대상) | 홈 할 일, 만들기, 편집, 함께 결정, 기록 + **에이전트 워크스페이스** | 레일/전역 메뉴 |
| **D2** | 화면 안의 상세 뷰 — URL을 갖고 브레드크럼에 쌓임 | 소재 카드 상세, 에피소드 실행 상세, 안건 상세, 카드 이력 | 목록 항목 클릭 |
| **D3** | 컨텍스트 패널·오버레이 — URL 없음, 닫으면 D2/D1로 복귀 | 선택 장면 패널, 바이블 요약 드로어, 확인 모달, 토스트 | 상세 안의 요소 클릭 |

## 전체 뎁스 트리

```
D0 에이전트 레일 ─┬─ D1 홈 할 일 (관제 + 받은편지함)
                 │    └─ 할 일 카드 → 해당 D1/D2로 딥링크 (홈 자체는 상세 없음)
                 ├─ D1 에이전트 워크스페이스 (에이전트 5개 × 동일 구조)
                 │    ├─ D2 소재 카드 상세 (요약·출처·맡기/확정·이력)
                 │    │    └─ D3 확정 확인, 출처 미리보기
                 │    ├─ D2 에피소드 실행 상세 (파이프라인 단계 + 활동 로그)
                 │    │    └─ (조립 완료 후) → D1 편집으로 연결
                 │    └─ D3 바이블 요약 드로어 (읽기 전용)
                 ├─ D1 만들기 (생성 플로우)
                 │    └─ D3 설정 칩, 진행률 (별도 D2 없음 — 실행 상세는 워크스페이스 소관)
                 ├─ D1 편집 (CapCut식)
                 │    └─ D3 선택 장면 패널, 이음새 재생, fact 출처 팝오버
                 ├─ D1 함께 결정
                 │    └─ D2 안건 상세 (선택지·득표·이력)
                 └─ D1 기록
                      └─ D2 카드/에피소드 이력 타임라인 (필터 고정 뷰)
```

## 내비게이션 규칙

1. **브레드크럼이 뎁스의 단일 표현이다.** 상단 바에 `홈 › 일본 머니 › 엔저
   시대 월급의 진실` 식으로 표시하고, 각 조각은 클릭해서 위로 올라간다.
   D3은 브레드크럼에 쌓이지 않는다.
2. **딥링크는 항상 D2까지.** 홈 할 일·알림·기록의 링크는 D2 상세로 직접
   떨어지고, 브레드크럼은 그 상세의 정상 경로로 복원된다.
3. **D2는 새로고침해도 그대로.** URL을 가지므로 서버 상태가 소스 오브
   트루스(생성 진행률 등). D3은 새로고침 시 닫힌다. localStorage로 뎁스
   상태를 보존하지 않는다(§10).
4. **한 화면에서 D3은 동시에 1개.** 패널을 연 채 다른 패널을 열면 먼저 것이
   닫힌다 — 편집 화면의 장면 패널은 예외적으로 상주형 D3.
5. **시점(보는 사람) 전환은 뎁스를 유지한다.** 단, 권한이 없는 D2(예: 타인
   소유 카드의 액션)는 읽기 전용으로 강등되고 잠금 안내를 띄운다.

## 뎁스별 권한 요약 (규칙 §5-4)

| 뎁스 | 잠금 동작 |
|---|---|
| D1 워크스페이스 | 전부 열람 가능 — 투명성 우선 (멀티에이전트 UI 원칙) |
| D2 카드 상세 | 열람은 전원, **상태를 바꾸는 액션**은 owner만 (셀프 검수 예외: 검토는 owner 불가) |
| D3 패널 | 상위 D2의 권한을 상속 |
