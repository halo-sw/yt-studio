# 예린이의 부동산 뽀개기 — 팀원 온보딩 (비개발자용)

> 코딩 몰라도 됩니다. **Claude Code에게 말로 시키는 구조**예요.

## 처음 한 번만 (세팅)

1. 이 레포를 받고 (`git clone` 또는 팀원이 복사해준 폴더), 폴더에서 **Claude Code**를 엽니다
2. `.env` 파일에 키 한 줄이 있는지 확인: `TYPECAST_API_KEY=...` (없으면 팀 공유 키를 붙여넣기 — **키 뒤에 주석 달지 말 것**)
3. 필요 프로그램: **Keynote**(맥 기본), **Google Chrome**, **node** — 대부분 이미 있음

## 평소 쓰는 법 (매물 → 영상, 두 마디)

Claude Code 채팅창에 이렇게 말하면 끝:

1. **"이번 주 뽀갤 매물 후보 보여줘"** → Claude가 후보 10개를 표로 보여줌 (`/yerin-scout`)
2. 마음에 드는 걸 고르고 **"3번으로 에피소드 만들어줘"** → 3~5분 뒤 완성 영상이 나옴 (`/yerin-episode`)

같은 매물을 다시 뽑을 땐 "재렌더해줘"라고 하면 Claude가 알아서 음성을 재사용해 **추가 과금 없이** 다시 만듭니다.

## 웹 화면이 편하면

터미널에 `.venv/bin/python cli.py ui` → 브라우저에서 `http://127.0.0.1:8787` → **부동산 탭** → 카드에서 "에피소드 생성" 클릭.
(Claude Code에게 "부동산 UI 켜줘"라고 해도 됩니다)

## 규칙 (중요)

- **소재 확정과 최종 검토는 사람이 합니다.** Claude는 후보를 보여주고 만들 뿐, 뭘 만들지·올릴지는 여러분이 결정
- 완성 영상은 `data/assets/produce/re-*/episode.mp4` — **유튜브 업로드는 직접** (Claude에게 시키지 마세요)
- 뭔가 이상하면 코드를 고치려 하지 말고 팀 채팅에 스크린샷과 함께 공유
