# 예린이의 부동산 뽀개기 — 사용법

> 코딩 몰라도 됩니다. 이 폴더에서 **Claude Code를 열고 말만 하세요.**

## 쓰는 법 (두 마디)

1. **"매물 보여줘"** → 후보 10개가 표로 나옴
2. **"3번으로 영상 만들어줘"** → 3~5분 뒤 완성 영상

끝. 다시 만들고 싶으면 "재렌더해줘".

## 처음 한 번만

- 맥에 Keynote·Chrome이 있으면 됨 (거의 다 있음)
- `.env` 파일에 `TYPECAST_API_KEY=팀공유키` 한 줄 확인 — 없으면 팀 채팅에서 받기

## 규칙

- 뭘 만들지 고르는 것과 유튜브 업로드는 **사람이** 합니다 (Claude에게 업로드 시키지 않기)
- 오류가 나면 고치려 하지 말고 팀 채팅에 화면 캡처 공유
