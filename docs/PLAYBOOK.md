# 숏폼 채널 플레이북 — 확정판 (클리핑 + 생성)

> **이 문서가 유일한 운영 기준이다.** plans/11~14는 검토 이력으로만 남기고 이 문서가 대체한다.
> 확정 사항: 자체 채널 주력 · 숏폼 중심 · 문체=냐옹체 · TTS=타입캐스트 · 편집=자체 파이프라인(FFmpeg).

---

## 0. 한눈 요약

| 항목 | 확정 내용 |
|---|---|
| 채널 | 기존 채널 피봇 (구독 1,000+ 보유) |
| 제작 레인 | **① 생성**(창작 스토리 + 생성 비주얼) 기본 · **② 클리핑**(라이선스 확보 원본 컷싱크) 조건부 |
| 발행량 | 쇼츠 매일 1편 + 주말에 그 주 1등 쇼츠의 롱폼 확장 1편 |
| 사람 시간 | 편당 ~20분 (소재 확정 · 제목 확정 · 업로드 승인) |
| 90일 목표 | 쇼츠 1,000만 뷰(쇼츠 수익화 요건) + 터지는 소재 축 데이터 확보 |

## 1. 두 제작 레인 — 언제 무엇을 쓰나

**레인 ① 생성 (기본값, 발행량의 80%+)**
창작 스토리 → 냐옹체 대본 → 생성/플레이스홀더 비주얼 → 렌더.
저작권 리스크 0. 소재는 무한(모티프 조합). 오늘부터 가능.

**레인 ② 클리핑 (조건 충족 시에만)**
원본 영상 컷싱크 리캡. **라이선스 근거(permission_ref)가 있는 원본만** — CC·퍼블릭도메인·제작자 제휴·자체 촬영분. 조건: 코드가 강제한다. 라이선스 메타 없으면 `ingest_source`가 거부하므로 우회 시도 금지. 시중 영화·드라마·타인 유튜브 영상은 **금지** (Content ID·경고 리스크, 규칙 5-5).

## 2. 일일 루틴 (총 ~30분, 나머지는 자동)

```
① 소재 (5분) — 아래 §4-A 프롬프트로 소재 3개 → 1개 확정
② 대본 (5분) — §4-B 프롬프트 → 출력 전문을 data/scripts/{슬러그}.txt 저장
③ 제작 (0분, 자동)
   python cli.py produce --script data/scripts/{슬러그}.txt --title "제목" --shorts
   → 린트 자동검수(위반 행만 재생성) → TTS → 렌더 → shorts.mp4 + meta.txt
④ 패키징 (5분) — §5 규칙으로 제목·썸네일 확정 (meta.txt 초안 활용)
⑤ 업로드 (5분) — 예약 18:00, 공개 전환은 사람이 (게이트)
⑥ 발행 직후 — 고정 댓글 1개 (질문 or 다음 화 예고)
```

클리핑 레인일 때는 ②③이 원커맨드로 합쳐진다 — **다운로드→클립 컷→대본→TTS→자막 번인→편집→쇼츠**:
```
python cli.py clip \
  --source "URL 또는 로컬파일" --title "제목" \
  --license-source "권리자" --license "CC-BY|제휴계약|자체제작" --permission-ref "근거" \
  --transcript 자막또는사건요약.txt --shorts
```
- `--source`에 URL을 주면 yt-dlp가 다운로드하고, 샷 경계를 자동 감지해 내레이션 길이에 맞춰 컷싱크한다.
- **허가 3종 인자가 없으면 다운로드 전에 멈춘다.** 이건 불편이 아니라 채널 보호 장치다 —
  타인의 유튜브·Douyin·영화 영상을 무단으로 넣는 순간 Content ID·경고로 채널 자산이 날아간다.

### 클리핑 소스 공급처 (허가 게이트를 통과하는 곳)

| 공급처 | 라이선스 | 용도 |
|---|---|---|
| Pexels · Pixabay · Mixkit | 무료 스톡 (상업 가능) | 분위기 컷·B롤 |
| Internet Archive | 퍼블릭 도메인 | 고전 영화 리캡 포맷 |
| 공공누리 1유형 | 출처 표시 | 공공기관 영상 |
| YouTube CC-BY 필터 | 저작자 표시 필수 | 업로더=권리자 검증 후만 |
| **숏무비 제작사 제휴 (핵심)** | 서면 허가 | 메일 1통 = 소스 수백 편. prompts/05 아웃리치 활용 |
| 자체 촬영/생성분 | 자체 제작 | 항상 가능 |

## 3. 대본 규격 (파이프라인 입력 계약)

- **한 행 = 한 절** (연결어 단위 줄바꿈 = 자막 호흡 = 씬 단위)
- 쇼츠: 15~20행 (60~90초) · 롱폼 확장판: 130~150행 (10분)
- 냐옹체 정량 스펙 (produce가 자동 검사):
  - 존댓말 고정 · 연결어 분포 ~했는데 40% / ~했고 25% / ~하자 15% / ~했죠 10% / ~했습니다 5%
  - 같은 연결어 3연속 금지 · "관객/시청자" 언급 금지 · 내면 묘사 최소화
  - 민감 표현은 자동 치환됨 (죽었다→세상을 떠났다 등) — 걱정 말고 스토리에 집중
- 마지막 행: 시그니처 질문 ("여러분이라면 ~했을까요?") — 채널 통일성의 핵심

## 4. 프롬프트 (이 2개만 쓴다 — Claude에 그대로 붙여넣기)

### A. 소재 (아침 5분)

```
너는 스토리텔링 쇼츠 채널의 기획자다. 아래 5축 중 {오늘의 축}에서
창작 스토리 소재 3개를 만들어라. 실존 영화·드라마·실화 재현 금지.

축: 미스터리→감동 / 직장 반전 / 일상 속 비밀 / 관계 회복 / 생존·긴장

각 소재마다:
- 로그라인 1줄 (첫 문장부터 궁금하게)
- 반전 1줄 (후반 70% 지점에 터질 것)
- 마지막 질문 1줄 (댓글 유도)
```

### B. 대본 (소재 확정 후 5분)

```
너는 스토리텔링 쇼츠 채널의 작가다. 아래 소재로 60~90초 대본을 써라.

[소재] {로그라인 / 반전 / 마지막 질문}

규칙:
- 한 행 = 한 절. 연결어(~했는데/~했고/~하자/~했죠/~했습니다)마다 행을 바꾼다.
- 15~20행. 존댓말 고정. 행동 중심 서술, 내면 묘사 금지.
- 연결어 분포: 했는데 40% / 했고 25% / 하자 15% / 했죠 10% / 했습니다 5%.
  같은 연결어 3연속 금지.
- "관객/시청자/보는 사람들" 언급 절대 금지.
- 첫 행 = 가장 강한 문장 (10초 시청 약속). 마지막 행 = 소재의 질문.
- 죽었다→세상을 떠났다, 살해→제거, 시체→쓰러진 사람으로 표현.
- 대본 텍스트만 출력 (번호·해설 없이).
```

## 5. 패키징 규칙

- **제목**: 3전략 중 택1 — 결과 궁금형("~하면 생기는 일") / 반전 암시형("~의 비밀") /
  숫자·시간형("30년간 ~"). 낚시 금지선: 대본에 없는 것을 약속하지 않는다.
- **썸네일 문구**: 6자 이내 대문구 + 12자 보조. 제목과 같은 문장 금지.
- **설명란**: meta.txt의 챕터 붙이고 첫 줄에 검색 키워드 문장. 3번째 줄 = 제휴 링크 슬롯.
- **예약 시간**: 쇼츠 18:00 고정 (4주 후 지표로 보정).

## 6. 주간 지표 루틴 (토요일 15분)

1. 이번 주 쇼츠 7편의 7일 조회수를 5축별로 합산
2. **상위 2축에 다음 주 물량 60% 배분, 최하위 축은 새 축으로 교체**
3. 주간 1등 쇼츠 → 일요일 롱폼 확장판(§4-B를 130~150행 스펙으로) 제작
4. 같은 스토리 훅만 바꾼 재업로드 금지 (중복 판정 리스크)

| 시점 | 목표 | 미달 시 |

| D+90 | 쇼츠 1,000만 뷰 또는 4,000시간 | 상위 축만 남기고 집중 or 피봇 재검토 |

## 8. 금지선 (요약 — 코드가 대부분 강제)

1. 라이선스 근거 없는 원본 클립 사용 금지 (ingest가 거부)
2. 실존 작품 줄거리 재현·배우 실명 금지
3. 조회수·수익 보장성 문구, 낚시 제목 금지
4. 셀프 승인 우회, 전체 재렌더로 부분 수정 대체 금지
5. 키(.env)는 절대 커밋 금지 — 채팅·문서에도 붙여넣지 않기

## 9. 명령어 치트시트

```bash
# 대본 → 완성 영상(본편 16:9 + 쇼츠 9:16 + meta.txt)
python cli.py produce --script data/scripts/파일.txt --title "제목" --shorts

# BGM 언더베드 포함 (에피소드 글로벌 트랙, -26 LUFS)
python cli.py produce --script ... --title ... --shorts --bgm bgm.m4a

# 클리핑 레인: 다운로드→클립→자막·TTS→편집→쇼츠 원커맨드
python cli.py clip --source URL --title "..." \
  --license-source ... --license ... --permission-ref ... \
  --transcript 자막.txt --shorts

# 클리핑 레인 e2e 데모 / 전체 파이프라인 점검
```
