# PART A — 협의로 확정한 전략

## A1. 우리가 합의해온 여정 (요약)

1. **"72시간 100만원"** 요청 → 즉시 광고수익은 구조적으로 불가함을 확인하고, 돈이 되는
   마지막 구간(영상 실제 산출)부터 완성하기로 합의 → **파이프라인 M1 완성** (실렌더 검증)
2. **냐옹무비류 리캡 포맷** 채택 요청 → 문체(냐옹체)를 정량 스펙으로 이식하되,
   무단 푸티지 대신 **합법 2레인(생성/허가 클리핑)**으로 같은 결과물을 내기로 합의
3. **자체 채널 주력** 확정 (대행·대본판매는 보류, 재가동 가능 상태 유지)
4. **숏폼 중심** 확정 — 쇼츠 데일리 + 검증된 소재만 롱폼 확장
5. TTS = **타입캐스트** (키 수령, .env 보관), 편집 = 자체 FFmpeg 파이프라인
   (CapCut은 공식 API가 없어 자동화 불가 — 우리 파이프라인이 그 역할을 대체)
6. 수강 강의 5강 + 외부 리서치 5종을 **검증 후** 선별 흡수 (A5 검증표)
7. 주력 카테고리 대본은 **실제 통계 기반**으로 작성 (사실 시트 + 출처 대장)

## A2. 목표와 수익 모델 — 정직한 수학

**목표 재정의**: 자체 채널 단독으로 90일 내 현금 1,000만원은 확률이 낮다(YPP 정산 시차).
따라서 90일의 목표는 **수익 파이프의 완성**이다 — 1,000만원은 90일 '내'가 아니라
90일이 만든 '시스템'이 벌어온다.

| 단계 | 기간 | 목표 | 기대 수익 |
|---|---|---|---|
| Phase 1 | D0~90 | 쇼츠 1,000만뷰(쇼츠 수익화 요건) 또는 시청 4,000시간 → YPP 완성 + 터지는 소재 데이터 확보 | 0~50만원 (낮게 잡음) |
| Phase 2 | D90~180 | 롱폼 시청시간이 수익 본체 (금전·사연 카테고리 RPM $2~5) | 월 80~600만원 구간 |
| Phase 3 | D180+ | 일본 수출·제작사 제휴·채널 복제, 필요시 대행(편당 15~30만원) 재가동 | 복리 |

- 쇼츠는 유입 장치(RPM 회당 ~0.1원대), **돈은 롱폼 시청시간에서 나온다.**
- 조기 현금이 필요하면: 제작 대행 즉시 재가동 (프롬프트·견적 템플릿 docs/prompts/05 보존).

## A3. 채널 정체성과 카테고리 (확정)

**정체성 = "돈과 사람이 얽힌 반전 사연"** — 스토리물의 바이럴 × 금융·직장 광고군의 고RPM.

| 순위 | 카테고리 | RPM | 주간 비중 | 준비된 대본 |
|---|---|---|---|---|
| 1 주력 | 금전·사기·상속 | ★★★ | 30% | phishing, junggo, yuryubun |
| 2 주력 | 직장·갑질 반전 | ★★ | 30% | drawer |
| 3 성장 | 미스터리 반전 | ★ | 30% | gyeongbiwon, bakery, delivery |
| 4 보조 | 부동산·정책 사연 | ★★★ | 10% | jeonse, gantong |
| 5 완충 | 가족·관계 회복 | 낮음 | 필요시 | milk |

**외부 교차 검증(2026 업계 데이터)**: 금융 니치 RPM $10~25(최상위), 서사·실화범죄
$6~13, 게임·엔터 $2~5 — 이 포지셔닝이 스토리물 중 광고 단가 최상 구간임을 확인.

# PART B — 일일 실행 매뉴얼

## B1. 제작 레인 2종

**레인 ① 생성 (기본 — 발행량 80%+)**: 창작 스토리 + 생성 비주얼. 소스 영상 불필요, 저작권 0.
**레인 ② 클리핑 (허가 소스 확보 시)**: 다운로드→샷 감지→컷싱크. 허가 3종 인자 필수(코드 강제).

```bash
# 레인 ① — 대본 파일 하나로 본편+쇼츠+메타까지
python cli.py produce --script data/scripts/파일.txt --title "제목" --shorts

# 레인 ② — URL/파일 → 다운로드 → 클립 → 자막·TTS → 편집 → 쇼츠
python cli.py clip --source "URL" --title "제목" \
  --license-source "권리자" --license "CC-BY|제휴계약|자체제작" --permission-ref "근거" \
  --transcript 자막.txt --shorts
```

클리핑 소스 공급처: Pexels·Pixabay(스톡) / Internet Archive(퍼블릭도메인) / 공공누리 /
YouTube CC-BY(권리자 검증 후) / **숏무비 제작사 제휴(핵심, D+60 아웃리치)** / 자체 제작분.

## B4. 대본 규격 + 품질 게이트

**규격**: 한 행 = 한 절(연결어 단위 줄바꿈 = 자막 = 씬). 쇼츠 15~20행 / 롱폼 130~150행.
마지막 행 = 시그니처 질문("여러분이라면 ~했을까요?").

**구성 = 기·전·승·결**: 훅(1~2행) → 반전·비상식 먼저 → 설명은 짧게 → 완전한 해소.
설명 3행 연속이면 재배치.

**자동 게이트 (produce가 강제)**: 연결어 분포(는데40/고25/자15/죠10/습니다5 ±허용)
· 3연속 금지 · 존댓말 · 관객 언급 금지 · 민감표현 자동 치환 · 사실시트 키 검증

**사람 게이트 — 훅 체크 (첫 행이 7기법 중 2개 이상)**:
구체 수치·시간 / 모순·비상식 / 인물+갈등 / 부정 명령("절대 ~하지 마세요") /
소외감("남들 다 아는") / 권위(창작 인물의 직업·경력) / 장면 한복판 시작

**민감 요소**: 성적 암시·폭력 직접 묘사·흡연 도박 약물 언급 금지, 아동 주인공 초기 회피, 욕설 0개

## B6. 프롬프트 2종 (이것만 쓴다)

### A. 소재

```

카테고리 {①금전·사기·상속 / ②직장·갑질 반전 / ③미스터리 반전 / ④부동산·정책 사연
/ ⑤가족·관계 회복} 중 {오늘의 카테고리}에서 창작 소재 3개를 만들어라.
실존 영화·드라마·실화 재현 금지.
{선택: 아래 모티프를 2~3개 결합해 재창작 — 원문 문장·인물 재사용 금지
 모티프: (스레드/마이너갤/뉴스 한 줄에서 건진 상황 뼈대)}

각 소재마다:
```

### B. 대본

```
너는 스토리텔링 쇼츠 채널의 작가다. 아래 소재로 60~90초 대본을 써라.

[소재] {로그라인 / 반전 / 마지막 질문}

규칙:
- 한 행 = 한 절. 연결어(~했는데/~했고/~하자/~했죠/~했습니다)마다 행을 바꾼다.
- 15~20행. 존댓말 고정. 행동 중심, 내면 묘사 금지. 시간 흐름은 "다음날/그날 밤/잠시 후".
- 연결어 분포: 했는데 40% / 했고 25% / 하자 15% / 했죠 10% / 했습니다 5%. 3연속 금지.
- "관객/시청자/보는 사람들" 언급 절대 금지.
- 첫 행 = 가장 강한 문장. 마지막 행 = 소재의 질문.
- 죽었다→세상을 떠났다, 살해→제거, 시체→쓰러진 사람.
- 실제 통계 인용 시 수치는 {{fact:키이름}} 토큰으로만.
- 대본 텍스트만 출력.
```

## B7. 패키징 공식

| 제목 공식 | 실례 |
|---|---|
| 숫자형 "N년간 ~한 이유" | "30년간 지하실 문을 지킨 경비원의 비밀" |
| 모순형 "~인데 ~한 사연" | "20년 무결근 직원이 가장 먼저 해고된 이유" |
| 결과형 "~하면 생기는 일" | "3년간 빈 박스를 배달하면 생기는 일" |

낚시 금지선: 대본에 없는 것을 약속하지 않는다.
썸네일: 대문구 6자 + 보조 12자, 제목과 다른 문장. 설명란: 키워드 1줄 → 챕터 → 제휴 슬롯 → 해시태그.
고정 댓글 = 대본 마지막 질문 재사용.

## B8. 지표 루틴

**편당 기록** (발행 익일 + 7일차):
`날짜 | 파일명 | 카테고리 | 24h 조회 | 7d 조회 | 완주율% | 구독전환 | 훅유형`

**3지표 진단**: 계속 시청함(3~5초) 나쁨→훅 수리 / 지속시간(90%+ 목표) 나쁨→설명 구간 축소 /
참여도 나쁨→질문·고정댓글 수리

**조회수 구간 진단**: 1만 미만=제작 문제(B4로) / 1~3만 정체=**소재 문제**(편집 수선 아니라 교체) /
3만 돌파=같은 카테고리 즉시 증산

**효율 배수 벤치마크**: 경쟁 채널에서 조회수/구독자 10배+ 영상 = 소재 신호 → 재창작 입력.
우리 채널이 1배 미만 지속 = 정체성 인지 문제.

**토요일 판단 규칙 (15분)**: ① 7d 랭킹 상위 2카테고리에 물량 60%, 최하위 교체
② 완주율 70%+ → 일요일 롱폼 확장(**반드시 8분+, 미달 시 보강**) ③ 완주율 40%↓ → 훅 반례 기록
④ 6h 내 조회 속도 3배+ → 즉시 2편 증산 ⑤ 2주 연속 상승 시에만 하루 2편 증설

**계절 규칙**: Q4(10~12월) CPM 40~60%↑ → 증설·재고 소진 시즌 / 1~2월 = 실험 시즌.
**속설 정리**: 쿠키 작업·VPN·2차 인증 선행 불필요, 수익창출≠조회 하락, 채널은 한 가지 결(핀셋).

## B9. 확장: 일본 수출 (D+30 이후) → 영어권 (D+90 이후)

- 언어별 알고리즘 분리 → **우리 창작 대본을 일본어 번역 수출 = 소재 1개로 영상 2개, 저작권 0.**
- 조건: 한국에서 3만+ 검증된 소재만. 문화 의존 낮은 것부터(미스터리·금전). 고유명사·화폐 현지화.
- 파이프라인: japan 트랙 + 타입캐스트 일어 성우 구조 기존재. 별도 채널 1개(기본 언어=일본어), VPN 불필요.
- 영어권(RPM 3~5배)은 일본 모델 검증 후에만.
- 다계정은 정상 운영 분리만 — 제재 회피 구조 금지.
