## 1. 제작 레인 2종

**레인 ① 생성 (기본값 — 발행량 80%+)**: 창작 스토리 + 생성 비주얼. 소스 영상 불필요, 저작권 0.
**레인 ② 클리핑 (허가 소스 확보 시)**: 원본 다운로드→샷 감지→컷싱크. 허가 3종 인자 필수(코드 강제).

```bash
# 레인 ① — 대본 파일 하나로 본편+쇼츠+메타까지
python cli.py produce --script data/scripts/파일.txt --title "제목" --shorts

# 레인 ② — URL/파일 → 다운로드 → 클립 → 자막·TTS → 편집 → 쇼츠
python cli.py clip --source "URL" --title "제목" \
  --license-source "권리자" --license "CC-BY|제휴계약|자체제작" --permission-ref "근거" \
  --transcript 자막.txt --shorts
```

클리핑 소스 공급처: Pexels·Pixabay(스톡) / Internet Archive(퍼블릭도메인) / 공공누리 1유형 /
YouTube CC-BY(권리자 검증 후) / **숏무비 제작사 제휴(핵심 — D+60 아웃리치)** / 자체 촬영·생성분.

## 2. 완전한 1편 제작 워크스루 (실례 — 이대로 따라 하면 됨)

**예: 미스터리 카테고리, 월요일 아침**

```
[08:00] ① 소재 (5분)
  §5-A 프롬프트에 "카테고리: 미스터리 반전" 넣고 실행 → 소재 3개 수신
  → "30년 잠긴 지하실" 선택 (훅 체크: 수치○ 미스터리○ → 통과)

[08:05] ② 대본 (5분)
  §5-B 프롬프트에 소재 카드 붙여넣기 → 출력 전문을
  data/scripts/basement.txt 로 저장 (한 행 = 한 절 확인)

[08:10] ③ 제작 (자동 ~3분)
  $ python cli.py produce --script data/scripts/basement.txt \
      --title "30년간 지하실 문을 지킨 경비원의 비밀" --shorts
  → 린트 자동검수 (위반 행 있으면 그 행만 §5-B로 재생성 후 재실행)
  → 산출: data/assets/produce/basement/
     ├ episode.mp4   (16:9 본편)
     ├ shorts.mp4    (9:16 쇼츠 — 이게 오늘 업로드분)
     └ meta.txt      (제목·챕터·설명 초안)

[08:15] ④ 패키징 (5분)
  제목 확정: §6 공식 3개 중 택1 (예: 숫자형 "30년간 ~의 비밀")
  썸네일: §6 규격 (대문구 "30년 봉인" + 보조 "열어보니...")

[08:20] ⑤ 업로드 (5분)
  Studio → shorts.mp4 → 제목/설명(meta.txt 붙여넣기+해시태그)
  → 예약 18:00 KST → 저장
  ※ publish.py 구현 후엔 이 단계도 자동 (OAuth 발급 대기)

[18:05] ⑥ 발행 직후 (2분)
  고정 댓글 1개: "여러분이라면 이 문을 열어봤을까요?" (대본 마지막 질문 재사용)
  지표 시트에 행 추가 (§7 양식)
```

**편당 사람 시간 합계: ~20분.** 이 사이클을 매일 1회.

## 4. 대본 규격 + 품질 게이트

**규격 (파이프라인 입력 계약)**
- 한 행 = 한 절 (연결어 단위 줄바꿈 = 자막 호흡 = 씬)
- 쇼츠 15~20행(60~90초) · 롱폼 확장판 130~150행(10분)
- 마지막 행 = 시그니처 질문 ("여러분이라면 ~했을까요?")

**자동 게이트 (produce가 강제 — 신경 쓸 필요 없음)**
- 연결어 분포 ~했는데40/했고25/하자15/했죠10/했습니다5 (±허용범위) · 3연속 금지
- 존댓말 · "관객/시청자" 언급 금지 · 민감표현 자동 치환(죽었다→세상을 떠났다 등)

**구성: 기승전결이 아니라 기·전·승·결** (강의 인사이트 — 쇼츠 전용 순서)
1. **기 = 훅** (첫 1~2행, 아래 기법) → 2. **전 = 반전·비상식 요소 먼저** (몰입 점화)
→ 3. **승 = 상황 설명은 짧게** (지루해지기 전에) → 4. **결 = 완전한 해소** (시청자가 원한 장면)
- 중간에도 지루해질 타이밍마다 비상식/반전 요소를 심는다. 설명이 3행 연속되면 재배치.

**사람 게이트: 훅 체크 — 첫 행이 아래 7기법 중 2개 이상 (미달이면 소재부터 다시)**
- [ ] 구체 수치·시간 ("30년", "99%", "매주 화요일") — 숫자는 기대감 장치
- [ ] 모순·비상식 ("박스는 늘 텅 비어 있었는데") — 보자마자 "뭐야?" 반응
- [ ] 인물+갈등 즉시 제시 ("행패 부리는 할아버지")
- [ ] 부정 명령 ("절대 ~하지 마세요") — 하지 말라면 더 궁금해짐
- [ ] 소외감 ("남들은 다 아는", "지금 해외에서 난리 난") — 나만 모른다는 심리
- [ ] 권위 부여 ("20년차 경비원이", "월 10억 사업가가") — 창작 인물의 직업·경력으로
- [ ] 설명이 아닌 장면 한복판 시작

**민감 요소 (노출 제한 방지 — 치환표에 추가로)**
- 성적 암시·노출 묘사 금지 / 폭력 장면 직접 묘사 최소화 / 흡연·도박·약물 언급 금지
- 아동이 주인공인 소재는 채널 초기(D+30 전) 회피 / 욕설 0개 원칙 (필요 시 "화를 냈다"로 서술)

## 4-A. 소재 상류 발굴 — 모티프는 최상류에서 (강의 인사이트 × 재창작 원칙)

트렌드는 상류→하류로 흐른다: **커뮤니티 최상류 → SNS → 유튜브 → TV(끝물)**.
남들이 이미 퍼간 유튜브가 아니라 최상류에서 **모티프만** 건져 재창작한다.

| 상류 소스 | 건지는 것 | 사용 규칙 |
|---|---|---|
| 스레드(Threads) | 분노글·자영업 썰·연애 갈등 모티프 | **원문 재사용 금지 — 모티프 2~3개 결합 재창작** (기존 natepan 원칙 그대로) |
| DC 마이너 갤러리 | 직군별 PTSD·최신 썰 (예: 자영업 갤) | 동일. "세 줄 보고 50초 썰" — 세 줄에서 얻는 건 상황 뼈대뿐 |
| 뉴스 한 줄 | 사건 개요 (예: 이물질 신고 기사) | 한 줄 사실 → 인물·과정·감정을 전부 창작 (스토리텔링이 본체) |
| 인스타/틱톡 해외 알고리즘 | 국내 미유입 소재 유형 | 포맷 아이디어만. 영상 자체는 가져오지 않음 |
| 구글 트렌드 | 수요 급증 이슈 | 이슈 자체가 아니라 "그 이슈를 소재로 한 창작 스토리" |

**수요·공급 관점 (조회수 진단의 전제)**: 조회수 부진은 편집 문제이기 전에 시장 문제다.
공급(같은 유형 영상)이 포화된 카테고리는 잘 만들어도 안 나온다 → §7 판단 규칙에서
카테고리 교체가 편집 수선보다 우선인 이유.

## 5. 프롬프트 2종 (이것만 쓴다)

### A. 소재 (아침용)

```
너는 스토리텔링 쇼츠 채널의 기획자다. 채널 정체성은 "돈과 사람이 얽힌 반전 사연"이다.
카테고리 {①금전·사기·상속 / ②직장·갑질 반전 / ③미스터리 반전 / ④부동산·정책 사연
/ ⑤가족·관계 회복} 중 {오늘의 카테고리}에서 창작 소재 3개를 만들어라.
실존 영화·드라마·실화 재현 금지.
{선택: 아래 모티프를 2~3개 결합해 재창작 — 원문 문장·인물 재사용 금지
 모티프: (스레드/커뮤니티에서 건진 상황 뼈대 붙여넣기)}

각 소재마다:
- 로그라인 1줄 — 훅 7기법(수치/모순/인물갈등/부정명령/소외감/권위/장면한복판) 중 2개 이상
- 반전 1줄 (후반 70% 지점)
- 마지막 질문 1줄 (댓글 유도)
- 광고 인접군 1줄 (예: 상속 분쟁 → 법률·보험 시청자)
```

### B. 대본 (소재 확정 후)

```
너는 스토리텔링 쇼츠 채널의 작가다. 아래 소재로 60~90초 대본을 써라.

[소재] {로그라인 / 반전 / 마지막 질문}

규칙:
- 한 행 = 한 절. 연결어(~했는데/~했고/~하자/~했죠/~했습니다)마다 행을 바꾼다.
- 15~20행. 존댓말 고정. 행동 중심, 내면 묘사 금지. 시간 흐름은 "다음날/그날 밤/잠시 후".
- 연결어 분포: 했는데 40% / 했고 25% / 하자 15% / 했죠 10% / 했습니다 5%. 3연속 금지.
- "관객/시청자/보는 사람들" 언급 절대 금지.
- 첫 행 = 가장 강한 문장. 마지막 행 = 소재의 질문.
- 죽었다→세상을 떠났다, 살해→제거, 시체→쓰러진 사람.
- 대본 텍스트만 출력.
```

(롱폼 확장판: 같은 프롬프트에 "130~150행, 10분. 4/7분 지점 직전 행은 클리프행어" 추가)

## 6. 패키징 공식 (실례 포함)

**제목 3공식 — 대본에 없는 것을 약속하지 않는다**

| 공식 | 형태 | 실례 (첫 배치) |
|---|---|---|
| 숫자형 | "N년간 ~한 이유/비밀" | "30년간 지하실 문을 지킨 경비원의 비밀" |
| 모순형 | "~인데 ~한 사연" | "20년 무결근 직원이 가장 먼저 해고된 이유" |
| 결과형 | "~하면 생기는 일 / ~해버린 결과" | "3년간 빈 박스를 배달하면 생기는 일" |

**썸네일**: 대문구 6자 이내(예: "30년 봉인") + 보조 12자(예: "문을 열자 전부 침묵").
제목과 같은 문장 금지 — 제목이 남긴 궁금증을 증폭.
**설명란**: 1줄 키워드 문장 → meta.txt 챕터 → 3줄째 제휴 링크 슬롯 → `#쇼츠 #사연 #반전`
**고정 댓글**: 대본 마지막 질문 재사용 (초기 댓글 밀도 = 노출 기여)

## 7. 지표 루틴 — 기록 양식과 판단 규칙

**편당 기록 (발행 익일 + 7일차, 시트 한 줄)**

```
날짜 | 파일명 | 카테고리 | 24h 조회 | 7d 조회 | 완주율% | 구독전환 | 훅유형(수치/모순/인물)
```

**3지표 진단 프레임 (강의 인사이트 — 어떤 지표가 뭘 말하는가)**

| 지표 | 의미 | 나쁘면 고칠 곳 |
|---|---|---|
| 계속 시청함(조회율) | 첫 3~5초에 '보기로 결정'했는가 | **훅** — 첫 1~2행·첫 장면 (§4 체크리스트) |
| 시청 지속 시간 | 보기로 한 사람이 얼마나 봤나. 90%+ 목표, 100%+ = 반복 시청 | **대본 연속성** — 승(설명) 구간 축소, 반전 배치 |
| 참여도 | 조회 대비 댓글·좋아요 | **마지막 질문 + 고정 댓글** |

**조회수 구간별 진단 규칙**
- **1만 미만**: 제작 문제 (훅·지속시간·민감요소 중 하나) → §4로 돌아가 해당 지표부터
- **1~3만에서 정체**: 제작은 통과, **소재(카테고리) 문제** → 소재 교체가 답, 편집 수선 아님
- **3만 돌파**: 소재 검증됨 → 같은 카테고리 즉시 증산

**판단 규칙 (토요일 15분)**
1. 7d 조회 기준 카테고리 랭킹 → **상위 2개에 다음 주 물량 60%**, 최하위 카테고리는 신규로 교체
2. 완주율 70%↑ 편 → 일요일 롱폼 확장판(130~150행) 제작 대상
3. 완주율 40%↓ 편 → 훅 유형을 기록해 §4 체크리스트에 반례로 추가
4. 조회 속도 이상 감지(발행 6h 내 평소 3배↑) → 해당 카테고리 소재 즉시 2편 추가 생산
5. **발행량 증설 규칙**: 하루 1편으로 시작 → 2주 연속 평균 조회 상승 시 하루 2편으로 (그 전엔 금지)

**운영 속설 정리 (강의 검증 — 헛수고 방지)**
- 쿠키 작업·VPN·2차 인증 선행: 전부 불필요 (시청/업로드 알고리즘 분리, 콘텐츠 베이스 판정)
- 수익 창출 켜면 조회수 하락: 근거 없음
- 채널 = 한 가지 결 (핀셋 카테고리): 유튜브가 채널을 "무엇 파는 집"으로 인지해야 피드를 준다

## 8-1. 확장 전략: 일본 수출 — 한 소재로 두 영상 (D+30 이후 개시)

**원리 (강의 인사이트)**: 유튜브 알고리즘은 언어별로 분리돼 있다. 우리가 쓴 **창작 대본을
일본어로 번역해 일본 타겟 채널에 올리면** 같은 소재가 별개 시장에서 다시 뛴다.
남의 영상을 번역하는 게 아니라 **우리 창작물의 자체 수출**이라 저작권 이슈가 0이고,
소재 1개 → 영상 2개로 제작 원가가 반값이 된다.

- **파이프라인 적합성**: japan 트랙(일어 길이 스펙)·타입캐스트 일본어 성우·언어별 바이블이
  이미 구조에 있다. 필요한 건 대본 번역 프롬프트 + 일본어 채널 세팅뿐.
- **채널 세팅**: 별도 채널 1개 (업로드 기본 언어=일본어). VPN 불필요 — 일본어 콘텐츠면
  일본 시청자에게 자동 노출.
- **수출 우선 소재**: 문화 의존도 낮은 것부터 (미스터리·금전 반전은 보편적, 한국 제도
  얽힌 소재는 제외). 감정 아크는 그대로, 고유명사·화폐만 현지화.
- **개시 조건**: 한국 채널에서 3만+ 검증된 소재부터 수출 (검증 없는 이중 제작 금지).
- **주의**: 채널 간 계정은 정상적으로 분리 운영하되, 제재 회피 목적의 다계정 구조는 만들지
  않는다. 채널이 늘어도 게이트(사람 검토)는 채널당 동일하게 적용.
