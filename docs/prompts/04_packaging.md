# 04 — 패키징: 제목 3안·설명·썸네일 문구·훅 검증

## A. 제목 3안 + 썸네일 문구

```
아래 대본의 제목 후보와 썸네일 문구를 만들어라.

[대본]
{대본 붙여넣기 또는 시놉시스}

출력:
1. 제목 3안 — 서로 다른 전략으로:
   ① 결과 궁금형: "~하면 생기는 일" / "~한 결과"
   ② 반전 암시형: "~의 비밀" / "알고 보니 ~"
   ③ 감정 직격형: 숫자·시간 포함 ("30년간 ~", "단 하루 만에 ~")
   각 안에 예상 클릭 심리 한 줄.
2. 썸네일 문구 2안 — 6자 이내 큰 글씨 + 12자 이내 보조 문구.
   제목과 같은 문장 금지(정보 중복 금지), 제목이 남긴 궁금증을 증폭하는 방향.
3. 설명란 첫 줄 (검색 키워드 포함 한 문장)

낚시 금지선: 대본에 없는 사실을 약속하지 않는다.
```

## B. 훅(첫 10초) 검증

```
아래는 영상의 첫 4행이다. 시청자가 이탈할 이유를 3개 찾고,
각각을 고친 첫 4행 대안을 출력하라. 판단 기준:
- 첫 문장에 '끝까지 볼 이유'가 있는가 (질문/모순/시간 압박)
- 4행 안에 구체적 장면이 그려지는가
- 설명으로 시작하지 않는가 (상황 한복판에서 시작해야 함)

[첫 4행]
{붙여넣기}
```

## C. 설명란 템플릿 (produce의 meta.txt에 이어 붙임)

```
{설명 첫 줄 — A의 3번}

{챕터 타임스탬프 — produce 자동 생성분}

#쇼츠 #스토리 #{소재 태그 2~3개}
```

- 제휴 링크 슬롯: 설명란 3번째 줄 고정 (plans/11 — 발행 시작과 동시에 켜두는 장치)
