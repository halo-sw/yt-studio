> Claude(웹/API)에 그대로 붙여 쓸 수 있고, 출력은 `cli.py produce`에 바로 들어간다.

## 공통 절대 원칙 (모든 프롬프트에 자동 포함됨 — 삭제 금지)

1. **저작권**: 실존 영화·드라마 줄거리 재현 금지. 창작 스토리 또는 복수 모티프 결합 재창작만.
   배우 실명·작품명·스틸 참조 금지. (규칙 5-5)
2. **민감 표현**: 죽었다→세상을 떠났다 등 치환표 준수 — 어차피 style_lint가 자동 치환하지만
   생성 단계에서 지키면 재생성이 줄어든다.
3. **수치**: 실제 통계·금액을 쓸 땐 {{fact:key}} 토큰 — 파이프라인이 사실 시트로 검증.
4. **출력 형식**: 대본은 **한 행 = 한 절(연결어 단위)**, 빈 줄 없이. 이 형식이 그대로
   자막 호흡·씬 단위가 된다.

## 표준 워크플로 (1편 기준, 사람 ~20분)

```
01로 소재 3개 뽑기 → 1개 확정(게이트 1)
→ 02 또는 03으로 대본 생성 → 대본.txt 저장
→ python cli.py produce --script 대본.txt --title "..." --shorts
→ 04로 제목·설명 확정 → Studio 예약 업로드 → 공개 전환(게이트 2)
```
