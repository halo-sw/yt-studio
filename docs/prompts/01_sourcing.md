# 01 — 소재 발굴 프롬프트

## A. 아웃라이어 역해부 (경쟁 채널에서 터진 소재 구조 추출)

```
너는 유튜브 콘텐츠 전략가다. 아래는 최근 2주 내 구독자 대비 조회수가 터진
영상들의 제목과 (있다면) 자막이다.

[분석 대상]
{제목/자막 붙여넣기 — scout 아웃라이어 산출물}

다음을 추출하라:
1. 공통 훅 구조 — 첫 10초에 무엇을 약속하는가
2. 소재의 감정 축 — 호기심/분노/감동/통쾌 중 무엇을 자극하는가
3. 이 구조를 "실존 작품과 무관한 창작 스토리"로 응용할 수 있는 소재 5개
   — 각각 한 줄 로그라인 + 핵심 반전 + 예상 타깃

주의: 원본 소재의 줄거리를 복제하지 말고 '작동 구조'만 응용한다.
```

## B. 소재 카드 생성 (확정용)

```
아래 로그라인을 소재 카드로 발전시켜라.

로그라인: {선택한 로그라인}

출력:
- 제목 후보 3안 (냐옹관식: "~하면 생기는 일", "~해버린 남자/여자", "~의 비밀")
- 3문장 시놉시스 (기승전결 압축, 반전 명시)
- 훅 첫 문장 (10초 내 시청 약속)
- 이야기의 감정 아크 5단계
- 쇼츠 1편으로 충분한가 / 롱폼 확장 가치가 있는가 판단 + 근거
```

## C. 소재 판단 기준 (사람 게이트 1 체크리스트)

- [ ] 실존 작품·실존 인물 서사와 겹치지 않는가
- [ ] 반전이 "말로 설명 가능"한가 (비주얼 의존 반전은 AI 이미지로 약함)
- [ ] 첫 문장만으로 끝까지 볼 이유가 생기는가
- [ ] 우리 채널 기존 시청자가 이질감을 느끼지 않는가 (피봇 연결고리)
