# 05 — 제작 대행 영업: 견적·브리프 응답 (수익 엔진 B)

## A. 재능마켓 상품 설명 (크몽/숨고 등록용)

```
[상품명] 유튜브 스토리·사연 영상 제작 대행 (대본+성우급 음성+편집 일괄)

[본문 구성 — 이 순서대로]
1. 결과물 스펙: 10분 롱폼 / 60초 쇼츠, 자막 번인, 챕터 타임스탬프,
   제목 3안 + 썸네일 문구 포함
2. 차별점: 대본 품질(전문 문체 스펙 적용), 3영업일 납품, 씬 단위 수정
   ("이 장면만 다시" — 전체 재작업 없음, 수정 2회 무료)
3. 프로세스: 소재 협의 → 대본 컨펌 → 완성본 → 수정
4. 가격: 쇼츠 5만원 / 롱폼 10분 20만원 / 월 8편 패키지 120만원
   (레퍼런스 확보기: 첫 3건 -30%)
5. 포트폴리오 링크 (자체 채널 = 상시 갱신되는 포트폴리오)

[금지] 조회수·수익 보장 문구 (허위광고), 저작권 원본 사용 암시
```

## B. 브리프 응답 템플릿 (문의 → 24h 내)

```
안녕하세요, {브랜드/채널명} 담당자님.

요청 주신 {주제} 영상, 아래와 같이 제작 가능합니다.

- 결과물: {길이/형식/자막/납품 포맷}
- 일정: 대본 시안 D+1, 완성본 D+3
- 금액: {견적}원 (수정 2회 포함, 씬 단위 수정이라 회전이 빠릅니다)
- 시안: 유사 톤 샘플 {포트폴리오 링크}

소재만 확정해 주시면 대본 시안을 먼저 보내드립니다.
```

## C. 아웃리치 (주 10건 — 수·금 각 5건)

대상: ① 대본만 팔리는 채널(편집자 구인 글) ② 신생 사연·스토리 채널 ③ 지역 업체 홍보영상
메시지 골자: "채널 {이름} {영상} 잘 봤습니다 → 우리가 {구체적 개선점 1개}를
해결할 수 있습니다 → 샘플 1편 무료로 만들어 보내드릴까요?" — 샘플 원가가
사실상 0이라는 게 우리 파이프라인의 영업 무기다.

## D. 납품 워크플로 (내부)

수주 → 소재 카드(01) 고객 컨펌 → 대본(02/03) 컨펌 → `produce` 렌더 →
04 패키징 → 납품. **고객 컨펌 2회가 우리 게이트 2곳을 대체한다.**
