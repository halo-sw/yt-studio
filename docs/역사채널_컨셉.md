# 역사 신규 채널 컨셉 — 「여인들의 조선」(가칭) (2026-07-29)

> 사용자 방향 반영: 조선왕조실록 등 사료 기반 + **복원왕식 "그 시절 재현 그림"** 비주얼,
> **신규 채널**로 개설. 52편 제목 테스트 통과(channels/소재함/미배정.md).

## 1. 채널 컨셉

- **한 줄**: 실록이 기록한 그날을, AI 재현 그림으로 걸어 들어가 보는 채널.
- **포맷**: 10~15분 낭독 다큐. 시대 재현 이미지가 주인공 — 씬마다 "그 시절 화면"이
  쭉 이어지고(궁궐 내전·저잣거리·의금부…), 내레이션이 실록 원문을 인용하며 서사 진행.
- **소재 축**: 궁중·여성·신분반전 서사 (52편 목록 확보). 장희빈 쇼츠 412K 실측이
  이 오디언스(4050 여성, 사연 채널과 동일 코드: 시집갈등·참교육·반전)의 존재 증거.
- **차별화 장치** (YPP 제네릭 방어 겸):
  ① 매 편 실록 원문 자막 인용(연월일 표기) = 신뢰 브리지 + "다른 100개 채널에 없는" 근거
  ② 재현 그림의 인물·복식·공간 앵커를 채널 바이블로 고정 = 채널 고유 화풍
  ③ "재현 상상도" 명시 = 정직 + AI 공개 정책 준수

## 2. 신규 채널 vs 톡톡드라마썰 내 시리즈 — 판단

| | 신규 채널 (사용자 선호) | 톡톡 내 시리즈 |
|---|---|---|
| 채널 정체성 | ✅ 깨끗함 — 다큐 톤 단독 | ⚠ 사연·드라마와 혼합 → 알고리즘 시청자 매칭 혼선 |
| 구독 1,000 요건 | ❌ 0에서 시작 | ✅ 이미 8,570 |
| 시청시간 4,000h | ❌ 0에서 시작 | ✅ 사연과 합산 |
| 장기 브랜드 가치 | ✅ 높음 | 보통 |

**결론: 신규 채널로 가되, 역할을 나눈다.**
- **90일 수익화 목표는 톡톡드라마썰이 담당** (재고 방출 + 사연 옴니버스 — 기존 전략 유지).
- **역사 채널은 지금 개설해 병행 성장** — 20~30편 규칙(6개월 고정 슬롯)을 처음부터 적용,
  수익화는 2번째 타자. 90일 시점에 구독 500~1,000 + 시청시간 축적이 현실 목표.
- 톡톡의 장희빈류 쇼츠는 역사 채널 쪽에 올린다(정체성 정리) — 단, 기존 쇼츠는 옮기지
  말고 그대로 둔다(비공개 전환 시 시청시간·조회 이력 손실).

## 3. 워크플로 (기존 파이프라인 재사용률 ~90%)

```
소재함 카드(52편 목록) 
→ [사람 게이트 1] 소재 확정
→ 대본 생성: 리텐션 공식 적용(충격 훅→90초 인터럽트→실록 인용 신뢰 브리지→훅 콜백)
   + fact_sheet(인물·연도·사건 = 실록/한국사DB 근거, 수치는 씬에 직접 쓰지 않음)
→ TTS: Typecast (보이스 오디션 필요 — 다큐 톤 저음, tones.json 씬별 감정)
→ 비주얼: higgsfield_gen 시대재현 프리셋 신설
   "조선 {장소·시대} 재현화, 단청·한복 고증, 시네마틱 부감/실내 자연광, 동일 화풍 앵커"
   전 씬 이미지 + 훅·절정 2~3컷만 모션. credits.Batch로 사전 고지
→ assemble: 기존 그대로 (Ken Burns + 타임드 자막 + BGM 언더베드 — 국악풍 무료 음원)
→ 썸네일 3안 (재현 그림 + 서술형 클리프행어 텍스트 존)
→ [사람 게이트 2] 최종 검토 → release (channels.yaml에 채널 추가 시 자동 라우팅)
→ 업로드: AI 공개 체크 ON + 설명란 "실록 기반 AI 재현 상상도" 고지 + 출처 목록
→ 쇼츠 재컷(0cr): 본편 재현 그림 세로 크롭 + 노랑 타이틀 문법 — 신규 채널 구독 엔진
```

신설 필요 작업 2개뿐: ① 시대재현 프리셋(higgsfield_gen에 프리픽스 추가) ② 채널 바이블
yaml(보이스·화풍 앵커·인용 표기 규칙). 나머지는 전부 기존 코드.

## 4. 비용 (편당, 12분 기준)

| 항목 | 수량 | 크레딧 |
|---|---|---|
| 재현 이미지 GPT Image 2 1k (핵심 10씬) | 10 | 40 |
| 재현 이미지 Z Image (나머지 ~25씬) | 25 | 4 |
| 모션 (훅+절정, Minimax 6초) | 2~3 | 12~18 |
| 썸네일 | 1 | 4 |
| **합계** | | **약 60~66cr/편** |

- Z Image 사극 품질은 1편에서 검증 — 미달이면 NB2 Lite(1cr)로 승급해도 +25cr.
- TTS ~6,800자/12분(9.5자/초 기준, 보이스 실측 후 보정). BGM은 무료 국악 음원으로 0원.
- 주 2편 = **월 ~520cr** — 톡톡 옴니버스와 병행해도 기존 크레딧 최소 원칙 안에서 수용 가능.

**전략 함의 3개:**
1. **사실(실록 인용) 기반은 살고, 창작 야담(사연 문법에 사극 스킨)은 죽는다.** 야담체
   제목·오디오드라마 톤 금지 — 해설 다큐 톤 + 실록 근거 유지가 생사선.
2. **구독 5,680 채널이 10만뷰** = 이 니치는 구독이 아니라 추천·탐색이 조회를 만든다
   → 신규 채널 콜드스타트 페널티가 작다 (신규 개설 판단의 추가 근거).
3. 조회 상위는 전부 60분+ 몰아보기 — 초기 12분 편들이 쌓이면 **합본 몰아보기 재편집
   (0cr)**을 정례화한다. 상위권 채널들은 지도·초상화·스톡 위주 비주얼이라
   "일관 화풍의 시대 재현 그림"은 비어 있는 차별화 축.
