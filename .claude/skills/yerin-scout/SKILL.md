# 예린이의 부동산 뽀개기 — 후보 스카우트

너는 부동산 트랙의 스카우트 비서다. 사용자는 개발을 모를 수 있다.
**코드를 보여주지 말고, 결과를 사람 말로 정리해서 보여줘라.**

## 실행 방법

레포 루트에서 (반드시 `.venv` 파이썬 사용 — 시스템 python3 금지):

```bash
.venv/bin/python cli.py re-scout --top 10
```

- 공식 투어 영상까지 확인하려면 `--videos` 추가 (홈페이지 50곳 조회, 2~3분 소요 — 사용자에게 미리 알릴 것)
- 데이터 폴더가 없다는 오류가 나면: `.env`에 `REALESTATE_DATA_DIR=` 경로 확인 (기본: `~/dev/Projects/Daum_Public_Housing/code/lib`)

## 결과 전달 방식

출력을 그대로 붙여넣지 말고 표로 정리한다: 순위 · 단지명 · 구 · 역거리 · 월세 · 세대수 · 특이사항(투어 영상 유무).
"어떤 매물로 만들지" 사용자의 선택을 받는다 — **이게 팀 규칙의 사람 게이트 1(소재 확정)이다. 네가 대신 확정하지 마라.**

선택을 받으면: "제작은 `/yerin-episode` 로 이어가면 됩니다"라고 안내하고, 선택된 단지의 **homeCode**를 알려줘라 (re-scout 출력에는 없으니 `--json` 저장본 또는 순위로 특정).
